# v0.31.5: 元ページを保護した検証コピー一式

実施日: 2026-09-09。Builder v0.31.5 / Connector v0.19.11。
元ページの対応表を取得した v0.31.4 の次工程。公開ページ・既存の手修正下書きは変更せず、独立した下書きと専用メニューで実サイト検証を進める。

## 実装

- 「既存ページを変更せず、採用ページ一式の検証コピーを作成」を明示選択した場合だけ専用処理へ進む。初期状態では選択しない。Connector v0.19.11以上と、完全な読み取り専用対応表が必要。
- 元の site key と検証IDから独立した名前空間をサーバーが決定。実行直前に元ページIDを再照合し、`wp_insert_post` に既存IDを渡さず、新しい下書きだけを作成する。[WordPress公式仕様](https://developer.wordpress.org/reference/functions/wp_insert_post/)
- メニューも専用の新規メニュー。公開テーマ位置へは割り当てず、各コピーの認証付きプレビューURLをcustomリンクとして保持する。ボタン・本文リンク・Elementor Proメニューを同じコピー先へ接続する。
- 同じ画面の再試行は同じ検証ID・ページ保存IDを使う。途中で4ページ作成後に中断した試験では、残り5ページのみ作成。既存のコピーはタイトルや本文を「修復」しない。
- 本文は変換経路では一度だけ保存。保存済みハッシュと識別子が一致すれば再保存せず確認結果を返し、手修正・削除・公開化・重複・不明なメニュー項目は409で停止する。メニューの公開割当はコピー作成前にも検査する。
- 画像取得中の本文変更を保存直前に再検査し、画像URLの書き換えで手修正を上書きしない。画像保存後にはレビュー保存のハッシュも更新する。
- 長い日本語・絵文字のページ名は検証用タイトルのみ短縮し、APIの文字数制限を超えないようにする。元ページ名は変更しない。
- 請求書PDF・Web資料の未接続は、明示的な検証コピーに限り未完了一覧に残して先へ進める。通常保存の未接続ゲート、構造検査、全対象端末の視覚QA、仮テキストの明示承認は維持。架空の資料・URLは生成しない。
- 成功表示は「本文保存」と「実画面・機能・公開の完了」を区別する。

## 制限と次工程

- 検証IDは同じ画面のメモリー内に保持する。画面再読み込み・再変換・構成変更後は新しい検証となる。別セッションから途中の検証を再開するUIはまだない。
- 実行ロックを時間切れで奪う処理は入れていない。通常終了/例外/終了ハンドラーで解除する。強制プロセス終了で残るロックは自動復旧対象外で、新しい検証か管理者による確認が必要。
- 実WordPressの同時編集/書き込みはDBトランザクションで完全隔離しているわけではない。検証作成・画像保存中のコピーをElementorで同時編集しない。
- メニューをテーマ位置に割り当てないことは、第三者が公開ページのWidgetでそのメニューを選ぶ操作まで防止するものではない。検証メニューを公開コンテンツから参照しない。
- 2026-09-09の実ブラウザ確認はMacロックにより停止。今回の実WordPress Connector更新、新規9コピーの作成、保存後のPC/Tablet/SP巡回、Pro編集・フォーム送信/受信はまだ未実施。公開ページ、元9下書き、公開メニューはこの工程では操作していない。
- 自動試験合格・Builder画素スコアは製品の99.9%完成率ではない。解除後に実WordPress保存再読込とリンク/機能を確認する。
