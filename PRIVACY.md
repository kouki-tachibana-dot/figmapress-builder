# Privacy Notice

FigmaPress does not require an account and does not include analytics or
advertising trackers in the public release.

## Data processed

- Figma file URL/key, Figma JSON, OAuth token, or Figma Personal Access Token
- WordPress site URL, username, Application Password or scoped Connector token,
  and generated page data
- Standard request metadata handled by the hosting provider, such as IP
  address, timestamp, user agent, and response status

## Data use and retention

Inputs and credentials are used only to complete the requested conversion or
WordPress draft creation. The application has no database and does not write
these values to server files or application logs. Figma OAuth tokens are
encrypted in an HttpOnly cookie. A Personal Access Token is retained in the
current tab's session storage unless the user explicitly opts into local
browser storage. WordPress Application Passwords are not retained. When the
user selects one-click Connector pairing, the site URL, username, and a
90-day, Connector-scoped token are retained in local browser storage. The
pairing can be revoked immediately in WordPress and removed from the browser.
Credentials are not returned in API responses. Hosting-provider infrastructure
may retain standard request metadata under its own operational and security
policies.

The Figma API and the user's WordPress site receive the data required for the
operation and apply their own privacy policies. Users should avoid pasting
personal data that is not needed for page generation.
